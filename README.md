# Object-Oriented Programming — UPF

A collection of laboratory exercises developed for the Object-Oriented Programming (POO) coursework at Universitat Pompeu Fabra (UPF).

The repository progresses from fundamental object-oriented programming concepts to more advanced implementations involving datasets, learning algorithms and numerical optimization.

## Overview

The repository contains five laboratory stages covering:

- Classes and objects
- Encapsulation and object-oriented design
- Reusable data structures
- Dataset representation and manipulation
- Algorithm abstraction
- Supervised learning structures
- Gradient descent
- Stochastic gradient descent
- Testing and experimentation

The exercises use Java in the first stages and C++ in the final laboratory.

## Laboratory structure

### Lab 1 — Object-oriented foundations

Introduces core classes and basic object-oriented design through components such as Record, Vector and test classes.

### Lab 2 — Dataset abstractions

Extends the previous structures with Dataset and StandarizedDataset classes, reusable records and vectors, and test programs.

### Lab 3 — Learning abstractions

Introduces a structured learning framework with Algorithm, Model and SupervisedLearner components, together with dataset handling and learner tests.

### Lab 4 — Optimization

Adds numerical learning algorithms, including Gradient Descent and Stochastic Gradient Descent, together with supervised learning and testing.

### Lab 5 — C++ implementation

The final laboratory contains C++ headers and source files for the learning framework, including dataset and record structures, models, gradient descent, stochastic gradient descent, supervised learning and test programs.
